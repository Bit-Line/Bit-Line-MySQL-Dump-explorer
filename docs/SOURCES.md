# Technische Primärquellen

Referenzen zur Implementierung, keine Behauptung vollständiger MySQL-Kompatibilität. Build- und Testergebnisse sind eigene lokale Prüfungen; siehe TESTBERICHT.md.

- MySQL 8.4 Reference Manual – mysqldump: https://dev.mysql.com/doc/refman/8.4/en/mysqldump.html
- MySQL 8.4 Reference Manual – String Literals: https://dev.mysql.com/doc/refman/8.4/en/string-literals.html
- Microsoft – List-View Controls Overview / Virtual List-View Style: https://learn.microsoft.com/en-us/windows/win32/controls/list-view-controls-overview
- Microsoft – Tree-View Control Reference: https://learn.microsoft.com/en-us/windows/win32/controls/tree-view-control-reference
- Microsoft – CreateFileW: https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew
- Microsoft – Format Specification Syntax, printf / wprintf: https://learn.microsoft.com/cpp/c-runtime-library/format-specification-syntax-printf-and-wprintf-functions

Keine externen Inhalte werden zur Laufzeit geladen. Die Referenzen werden weder für den Build noch zum Öffnen eines Dumps benötigt.
